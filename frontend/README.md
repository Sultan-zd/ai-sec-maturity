# AIMA — Frontend (React + TypeScript)

Interface web de la plateforme AIMA. Voir [docs/07-frontend.md](../docs/07-frontend.md).

```bash
npm install
npm run dev      # http://localhost:5173 (le backend doit tourner sur http://localhost:8090)
npm run build    # vérification TypeScript + build de production dans dist/
npm run lint     # analyse statique (oxlint)
```
